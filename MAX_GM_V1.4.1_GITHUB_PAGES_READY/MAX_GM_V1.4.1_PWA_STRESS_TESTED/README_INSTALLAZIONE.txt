MAX GM V1.4.1 — PWA INSTALLABILE

Questo pacchetto è costruito come MAX LIVE: index.html + manifest + service worker + icone 192/512 + supporto offline.

IMPORTANTE
Per vedere il pulsante INSTALLA e usare il funzionamento offline, la cartella deve essere pubblicata su HTTPS. Aprire index.html direttamente come file locale non basta per installare una PWA.

METODO PIÙ SEMPLICE (come MAX LIVE)
1. Estrai questo ZIP.
2. Carica l'intera cartella su un hosting HTTPS statico (es. Netlify Drop).
3. Apri l'URL dal telefono con Chrome.
4. Premi INSTALLA dentro MAX GM oppure menu Chrome > Installa app / Aggiungi a schermata Home.

I dati dell'app continuano a essere salvati nel browser/localStorage del dispositivo, come nella versione HTML.
