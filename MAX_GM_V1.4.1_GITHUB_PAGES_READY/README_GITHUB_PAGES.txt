PUBBLICAZIONE RAPIDA
1. Crea su GitHub un repository PUBBLICO chiamato max-gm.
2. Carica TUTTI i file e la cartella icons nella ROOT del repository.
3. Vai in Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /(root).
7. Salva e attendi la pubblicazione.
8. Apri https://TUO-USERNAME.github.io/max-gm/
9. Da Chrome Android usa INSTALLA nell'app oppure menu > Installa app.

AGGIORNAMENTI FUTURI
Quando ricevi una nuova versione MAX GM:
- sostituisci index.html, manifest.webmanifest, service-worker.js e le icone se cambiate;
- conserva .nojekyll;
- fai commit su main;
- GitHub Pages ripubblicherà automaticamente il sito.

NOTA
Con GitHub Free, per GitHub Pages il repository deve essere pubblico.
